Formulasi Matematika Reward DQN:

Reward = R_soc + R_temp - Penalty_degradation
R_soc  = +1.0  jika 20% <= SoC <= 90% else -3.0
R_temp = +1.0  jika 15°C <= Temp <= 35°C else -4.0
FastCharge_Penalty = -2.0 jika Action==3 & Temp > 32°C
Degradation_penalty = (Degradasi SoH) * 25.0

Model Simulasi Degradasi SoH:

Degradation = 0.00008 + Temp_pen + Current_pen + DoD_pen
Temp_pen    = max(0, Temperature - 35.0) * 0.00008
Current_pen = (abs(Current) / 120.0) * 0.00005
DoD_pen     = max(0, Depth_of_Discharge - 80.0) * 0.00003
